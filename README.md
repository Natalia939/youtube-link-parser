# 🎬 YouTube Link Parser (`watch.py`)

A Python script that extracts YouTube video links from HTML `<iframe>` tags and converts them into shareable short URLs.  
This project demonstrates **regex (regular expressions)**, **string parsing**, and **input handling** — essential skills for web automation and data processing.

---

## 📘 Overview

Web pages often embed YouTube videos using HTML `<iframe>` tags like this:

<iframe src="https://www.youtube.com/embed/dQw4w9WgXcQ"></iframe>
